# Việt Nam Online — bản web v0.1

Du lịch 3D trên trình duyệt, nhiều người chơi. Bản này có khu Sông Hàn & Cầu Rồng (Đà Nẵng), chạy theo giờ và thời tiết thật.

```bash
npm install
npm run dev     # http://localhost:5173
```

Production: `npm run build && PORT=8787 npm start`.

Thử nhanh: `/d/danang?gio=21:00` để vào phòng riêng lúc 21h, rồi bấm "Xem lại" để xem rồng phun lửa.

Phạm vi, kiến trúc và các điểm điều chỉnh so với kế hoạch: xem `../03-Ban-web-v1.md`.
